# apps/miniprogram/

WeChat Mini Program entry for **机甲挑战计分板**.

## Phase 1 (T+2 weeks) — Taro 4 initialization

This directory will be initialized with **Taro 4** during Phase 1 (see `docs/mecha-challenge-phase1-task-card.md`).

**What to do in Phase 1:**
- `npm create taro@latest .` in this directory
- Install Taro 4 + dependencies
- Configure WeChat App ID
- Set up routing: `pages/auth/`, `pages/home/`, `pages/question/`, `pages/profile/`
- Import domain types from `packages/shared`

## Phase 0 scope

For now this directory is a **placeholder only**. No Taro 4, no wx API calls.
